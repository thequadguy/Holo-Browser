## 2. Stakeholder Value Arguments

- **Why Developers Respect It**: Built 100% natively in Swift 6 with zero Electron overhead, complete strict concurrency compliance, and open-source architecture.
- **Why Privacy Users Trust It**: Device-only Keychain security (`ThisDeviceOnly`), zero telemetry tracking, and mandatory regex AI context sanitization.
- **Why Mac Users Love It**: Native SwiftUI glassmorphic interface, sub-0.5s cold launch times, ProMotion 120Hz liquid smooth scrolling, and Spotlight `Cmd + K` Command Palette.
