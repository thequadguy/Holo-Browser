## 1. Feature Discoverability Assessment

| Feature | Primary Access Point | Keyboard Shortcut | Discoverability Rating | Recommendation |
|---|---|---|:---:|---|
| **Command Palette** | Address Bar Icon / Shortcut | `Cmd + K` | **High (5/5)** | Prominently featured in address bar tooltip |
| **AI Sidebar** | Sparkle Toolbar Icon | `Cmd + Shift + A` | **High (5/5)** | Auto-opens when summarizing or asking page |
| **Profile Switcher** | Profile Badge in Toolbar | `Cmd + Shift + P` | **High (5/5)** | Displays profile name & color badge |
| **Private Browsing** | File Menu / Shortcut | `Cmd + Shift + N` | **High (5/5)** | Dark purple theme indicator |
| **Password Manager** | Preferences > Passwords | `Cmd + ,` | **High (5/5)** | Dedicated Key icon tab in Preferences |
| **Research Workspace** | Sidebar Menu | `Cmd + Shift + R` | **Medium (4/5)** | Add quick-access button in AI sidebar |
| **Workspaces** | Sidebar Menu | `Cmd + Shift + W` | **Medium (4/5)** | Add Quick Switcher in Command Palette |

## 2. Recommendation Summary

Feature discoverability is excellent. Core productivity features (Command Palette, AI Sidebar, Profiles, Private Mode) are accessible via intuitive single-click icons and standard macOS keyboard shortcuts.
