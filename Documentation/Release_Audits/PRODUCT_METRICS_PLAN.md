# Holo Browser 1.0 — Product Metrics Plan

**Author**: Head of Product Analytics  
**Date**: July 30, 2026  

---

## 1. Metric Definitions & Target Thresholds

- **Onboarding Completion**: Target > 85% completion rate of 6-step onboarding wizard.
- **7-Day Retention**: Target > 40% active usage on Day 7.
- **Command Palette Adoption**: Target > 65% of active users using `Cmd + K` daily.
- **AI Feature Engagement**: Target > 50% of active users generating 1+ AI summaries weekly.
