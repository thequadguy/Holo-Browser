# Holo Browser 1.0.0 (Public Beta 1) — Release Notes

---

## 🌟 Highlights & Features

Holo Browser is the next-generation native macOS browser built with SwiftUI, AppKit, WebKit, and human-in-the-loop AI productivity tools.

### 🎨 Holo Liquid Glass User Interface
* Native macOS system vibrancy titlebar with transparent tab bar.
* Responsive liquid glass design optimized for Apple Silicon ProMotion displays (120 FPS).

### 🛡️ Privacy-First AI Operating Layer
* **Human-in-the-Loop AI**: AI workflow plans and browser actions display interactive preview modals for explicit user consent.
* **Zero Autonomous Purchases**: Checkout buttons, password entries, and payment forms are permanently blocked.
* **Apple Keychain Integration**: User credentials stay in macOS Keychain. Private browsing tabs write zero data to disk.

### ⚡ Local Intelligence & CoreML Runtime
* On-device AI query execution utilizing Apple Silicon Neural Engine or local Ollama (`127.0.0.1:11434`) servers with zero external network transmission.

---

## 💻 System Requirements
* **OS**: macOS 14.0 (Sonoma) or macOS 15.0 (Sequoia).
* **Architecture**: Apple Silicon (M1/M2/M3/M4) or Intel Core i7/i9.
* **Disk Space**: 25 MB free space.
