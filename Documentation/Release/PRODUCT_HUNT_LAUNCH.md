# Holo Browser 1.0 — Product Hunt Launch Copy

**Tagline**: Arc's modern workflow + Safari's speed & battery + strict AI privacy.

**Description**:
Holo Browser is a native macOS web browser built with SwiftUI and WebKit. It features strict profile data isolation, device-only Apple Keychain security, an AI privacy pipeline that redacts sensitive data, and a Spotlight-style `Cmd + K` Command Palette.
