**Author**: Head of Product Operations & DevRel Lead

## 1. Community Infrastructure Architecture

- **Public Discord / GitHub Discussions**: Structured channels for #general, #bug-reports, #feature-requests, and #local-ai.
- **In-App Feedback Integration**: Submissions via `BetaStatusView.swift` automatically generate triaged GitHub issues.
- **Bi-Weekly Release Notes**: Published on website and in-app via Sparkle update alerts.
