# HOLO BROWSER — CLOSED BETA TESTER ONBOARDING GUIDE

## 🎯 Welcome Beta Testers!

Thank you for testing Holo Browser v3 — the native, Liquid Glass web browser built exclusively for macOS using Swift, SwiftUI, AppKit, and WebKit.

---

## ⚡ Top 5 Shortcuts To Try First

1. **`⌘L` (Address Bar Focus & Smart Search)**: Type any URL, or prefix your query with `h ` to ask HoloMind AI directly (e.g. `h summarize quantum computing`).
2. **`⌘K` (Command Palette)**: Open the command palette to search open tabs, trigger HoloMind actions, or switch profile spaces.
3. **`⌘⇧A` (HoloMind AI Sidebar)**: Toggle the on-device AI assistant sidebar for page context summaries and research notes.
4. **`⌘T` / `⌘W` / `⌘⇧T`**: Create new tabs, close active tabs, or restore recently closed tabs with isolated profile history.
5. **`⌘,` (Settings & Preferences)**: Configure Isolated Profiles (Personal, Work, Private), AI Provider models, and inspect privacy metrics.

---

## 💬 How To Submit Feedback

- Click the speech bubble icon in the top toolbar or press `⌘K` and type **"Send Feedback"**.
- Use the **"Export Diagnostics"** button to copy anonymized system hardware logs if reporting a crash.
