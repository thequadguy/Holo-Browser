# HOLO BROWSER — BETA USER FEEDBACK COLLECTION GUIDE

## 💬 Native Feedback Submission System

Beta testers can submit real-time bug reports and feature requests directly from within Holo Browser:

1. **Toolbar Quick Feedback**: Click the speech bubble icon in the top toolbar or select `Help -> Submit Beta Feedback`.
2. **Dogfood Diagnostics Importer**: Optional checkbox to attach anonymized performance logs and hardware specs (`DiagnosticsExporter.swift`).
3. **Command Palette Shortcut**: Press `Cmd+K` and type `Submit Feedback`.
