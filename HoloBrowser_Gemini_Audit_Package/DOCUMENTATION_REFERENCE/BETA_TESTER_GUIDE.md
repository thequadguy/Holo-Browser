# Holo Browser 1.0 — Beta Tester Guide

Welcome to the Holo Browser 1.0 Beta Testing Program!

## 🧪 Testing Checklist & Scenarios

1. **Multi-Profile Testing**:
   - Create a **Work** profile and a **Personal** profile (`Cmd + Shift + P`).
   - Log into a web account on Profile A. Verify Profile B requires login and does not share cookies.

2. **Private Browsing Testing**:
   - Open a Private Window (`Cmd + Shift + N`).
   - Confirm cloud AI requests are blocked and history is not recorded.

3. **AI Context Assistance**:
   - Highlight text on a webpage and click **Explain** or **Summarize**.
   - Verify responses generate quickly and accurately.

4. **Command Palette**:
   - Press `Cmd + K` to filter open tabs or execute actions instantly.

5. **Tab Stress Testing**:
   - Open 20+ tabs. Verify background tabs suspend cleanly without memory leakage or UI stuttering.
