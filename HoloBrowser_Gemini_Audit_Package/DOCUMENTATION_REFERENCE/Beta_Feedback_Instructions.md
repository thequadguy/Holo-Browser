# Holo Browser 1.0 — Beta Feedback Instructions

Thank you for testing Holo Browser 1.0 Public Beta!

## How to Submit Feedback & Bug Reports

1. **In-App Diagnostics**:
   - Open **Preferences > Diagnostics** (`Cmd + ,` -> Diagnostics tab).
   - Click **Export Sanitized Diagnostic Log** to save a privacy-safe diagnostic summary.

2. **Submitting Reports**:
   - Submit bug reports via GitHub Issues or email: `beta@holobrowser.com`.
   - Include macOS version, Mac model, and steps to reproduce.
   - Do NOT include passwords, personal API keys, or private browsing URLs.
