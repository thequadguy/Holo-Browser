# Holo Browser 1.0 — Installation Instructions

## System Requirements
- Apple Silicon (M1/M2/M3/M4) or Intel Mac
- macOS 14.0 (Sonoma) or macOS 15.0 (Sequoia)
- 4 GB RAM (8 GB recommended for high tab counts)

## Step-by-Step Installation

1. Download **`HoloBrowser.dmg`** from the official release portal.
2. Double-click **`HoloBrowser.dmg`** to mount the disk image.
3. Drag **Holo Browser** into your **Applications** folder.
4. Launch **Holo Browser** from Applications or Spotlight (`Cmd + Space`).
5. On first launch, follow the onboarding screen to select your primary profile and optional AI provider.

## Gatekeeper Verification
Holo Browser is signed with a valid Developer ID Application certificate and notarized by Apple. If prompted by macOS Gatekeeper, click **Open** to run.
