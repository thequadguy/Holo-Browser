## 2. App Store & Website Copy

### App Store Description:
Holo Browser is designed specifically for Mac users who demand extreme speed, fluid productivity, and strict data privacy.

**Features**:
- Sub-0.5s cold launch times on Apple Silicon
- Per-profile `WKWebsiteDataStore` data isolation (Work vs Personal vs Private)
- Device-only Apple Keychain password security (`ThisDeviceOnly`)
- Mandatory AI context regex scrubbing for passwords, tokens, API keys, and credit card numbers
- Spotlight-style `Cmd + K` Command Palette
- Non-persistent Private Browsing mode with automatic cloud AI shield
