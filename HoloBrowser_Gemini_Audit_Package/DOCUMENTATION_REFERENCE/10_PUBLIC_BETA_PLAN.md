# Holo Browser: Public Beta Distribution & Community Feedback Plan

---

## 1. Beta Distribution Channels
* **Direct `.dmg` Download**: Distributed via official website (`https://holobrowser.com/download`).
* **Signed Sparkle 2 Updates**: Automatic background update delivery for public beta users on the `beta` channel.

---

## 2. Telemetry & Feedback Strategy
* **Privacy-First Diagnostics**: Anonymous crash reporting (`CrashReporter.swift`) collecting stack traces and OS versions only (opt-in).
* **Community Issue Tracker**: GitHub Issues repository for user feature requests and bug reports.

---

## 3. Post-1.0 Roadmap Strategy
1. **Spatial Browser Windowing**: Multi-canvas spatial window placement for macOS Sequoia.
2. **WebExtensions MV3 Marketplace**: Native extension gallery and developer submission portal.
