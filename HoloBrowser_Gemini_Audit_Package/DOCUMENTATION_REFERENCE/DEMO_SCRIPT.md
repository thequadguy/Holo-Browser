# Holo Browser 1.0 — Product Demo Scripts

## 30-Second Elevator Demo Script ("Why Holo Browser?")

- **[0:00-0:05]**: Open Holo Browser. Highlight sub-0.5s cold launch time.
- **[0:05-0:12]**: Press `Cmd + K` to open the Spotlight Command Palette. Type a query to switch tabs and switch from Personal to Work profile instantly.
- **[0:12-0:20]**: Highlight text on a webpage. Click "Summarize". Show the Privacy Shield indicator scrubbing sensitive passwords and API keys before query dispatch.
- **[0:20-0:30]**: Open a Private Window (`Cmd + Shift + N`). Show cloud AI block status and zero-RAM memory consumption.
