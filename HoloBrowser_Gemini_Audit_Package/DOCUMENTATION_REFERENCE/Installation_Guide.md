# Holo Browser 1.0 — Installation Guide for Mac Users

Welcome to Holo Browser! Installation takes less than 1 minute on macOS.

## Step-by-Step Instructions

1. **Download**: Download `HoloBrowser.dmg` from the official portal.
2. **Mount**: Double-click `HoloBrowser.dmg` in your Downloads folder to mount the disk image.
3. **Install**: Drag **Holo Browser** into your **Applications** folder shortcut.
4. **Launch**: Open Applications and double-click **Holo Browser** (or press `Cmd + Space` and search "Holo Browser").
5. **Gatekeeper Prompt**: Click **Open** on the standard Apple Gatekeeper prompt. Holo Browser is signed with a Developer ID certificate and notarized by Apple.
