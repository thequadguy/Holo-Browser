# Holo Browser — Community Guidelines

We welcome constructive feedback, bug reports, and feature suggestions from all beta testers.

1. **Be Respectful**: Treat all community members, developers, and testers with courtesy.
2. **Protect Privacy**: Never post passwords, API keys, private browsing URLs, or personal data in public issue trackers.
3. **Use Sanitized Logging**: Always use the built-in diagnostic log exporter when attaching logs.
