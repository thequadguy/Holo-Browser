# Holo Browser 1.0 — Known Issues

1. **Manifest V2 Extensions**: Legacy Manifest V2 extensions using background pages are deprecated. Holo Browser supports native WebKit WebExtensions and select Manifest V3 extensions.
2. **Local LLM Performance**: Running 70B parameter models requires 32GB+ Unified Memory. 7B/8B GGUF models are recommended for 8GB/16GB Macs.
