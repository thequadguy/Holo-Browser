## Major Post-1.0 Innovation Pillars

### 1. Spatial Web Canvas (v2.0)
* Interactive visual node graph linking open tabs, notes, web summaries, and research documents on a infinite spatial macOS canvas.

### 2. Autonomous Web Task Execution (v3.0)
* AI agents capable of completing multi-step web forms, booking flights, and extracting structured web data under human supervision.

### 3. Encrypted iCloud Sync (v1.5)
* End-to-end encrypted tab group, bookmark, and memory sync across Mac devices using CloudKit (`CKEncryptedRecordValue`).
