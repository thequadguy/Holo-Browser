# Holo Browser Landing Page & Beta Portal

This directory contains the public landing page and private beta portal for Holo Browser.

## Pages
- `index.html`: Product landing page featuring key architectural highlights.
- `style.css`: Modern liquid glass dark mode stylesheet.
- `privacy.html`: Zero-telemetry and Apple Keychain privacy policy.
- `beta.html`: Download portal for `HoloBrowser-RC2-Beta.zip`.
