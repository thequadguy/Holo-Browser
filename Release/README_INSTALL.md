# Holo Browser 1.0 RC2 — Installation Guide

Thank you for participating in the Holo Browser 1.0 RC2 Private Beta!

---

## 🚀 Quick Setup Instructions

1. **Extract Archive**: Double-click `HoloBrowser-RC2-Beta.zip` if it did not auto-extract.
2. **Move to Applications**: Drag `Holo Browser.app` into your macOS `/Applications` folder.
3. **Launch Application**: Open Finder -> Applications -> Double-click **Holo Browser.app** (or search `⌘Space` -> Holo Browser).
4. **Onboarding**: Complete the 3-step setup modal to import bookmarks or set default browser preferences.

---

## 🔒 Security & Privacy Notice

- All credentials remain secured in **Apple Keychain** (`Security.framework`).
- Private tabs write zero history or session files to disk.
- Code signatures are validated using native macOS `Security.framework` static code verification.
