# Holo Browser 1.0 — Public Beta Readme

Welcome to **Holo Browser 1.0 Public Beta** — a high-performance native macOS web browser built with SwiftUI, WebKit, and Swift 6 strict concurrency.

---

## 🌟 Key Features

- 🏎 **Native SwiftUI & WebKit**: Extreme speed, fluid animations, and low memory consumption on Apple Silicon.
- 🔒 **Isolated Browser Profiles**: Work, Personal, and Private profiles maintain strict data isolation via independent `WKWebsiteDataStore` containers.
- 🛡 **Mandatory AI Privacy Pipeline**: Context-aware AI assistance features scrub passwords, bearer tokens, JWTs, API keys, and credit cards before queries leave your Mac.
- 🔑 **Apple Keychain Security**: Credentials and API keys use `kSecAttrAccessibleWhenUnlockedThisDeviceOnly` to prevent iCloud exposure.
- ⚡️ **Spotlight Command Palette**: Press `Cmd + K` anywhere to launch tabs, search history, switch profiles, or execute AI workflows.

---

## 💻 System Requirements

- Apple Silicon or Intel Mac running **macOS 14.0 (Sonoma)** or **macOS 15.0 (Sequoia)**.
