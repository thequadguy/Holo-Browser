# Holo Browser 1.0 — Troubleshooting & Support Guide

## Common Solutions

### 1. Gatekeeper Warning on macOS
- If macOS displays "App cannot be opened because it was downloaded from the Internet", go to **System Settings > Privacy & Security** and click **Open Anyway**.

### 2. Resetting a Profile
- If you wish to reset a profile, navigate to **Preferences > Profiles** (`Cmd + ,`) and click **Reset Profile Cache**.

### 3. Exporting Diagnostic Logs
- Open **Preferences > Diagnostics** and click **Export Diagnostic Log** to save a privacy-scrubbed diagnostic text file for support.
